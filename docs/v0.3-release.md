# v0.3.0 Release Notes

This release adds operational observability, controlled CVE enrichment, and secure Python package publishing.

## Highlights

- Read-only operational metrics API and dashboard panel.
- Secure tag-driven PyPI publishing workflow using GitHub OIDC trusted publishing.
- Explicit CVE enrichment modes: `off`, `offline`, and `online`.
- Operator-supplied offline CVE feeds.
- Authenticated `/api/v1/cve/lookup` endpoint.

## Safety

CVE enrichment is separate from heuristic port-risk hints. An open port is not treated as evidence of a vulnerability. Online enrichment must be explicitly enabled and is non-critical to scan execution.
